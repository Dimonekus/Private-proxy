# Архитектура

## Общая схема

```
┌──────────────────────────── PrivateProxy.exe (WPF, asInvoker) ────────────────────────────┐
│  MainWindow (UI + трей)                                                                   │
│      │                                                                                    │
│      ▼                                                                                    │
│  MainViewModel ──► StrategyCatalogLoader   (data/strategies/*.json)                      │
│      │        ──► EngineLocator            (engine/manifest.json + SHA-256)              │
│      │        ──► WinwsRunner ────────────────► winws.exe  (дочерний процесс)             │
│      │        ──► StrategyTester ─────────────► winws.exe  (по одной стратегии)           │
│      │        ──► AutostartService         (schtasks, задача ONLOGON /RL HIGHEST)         │
│      │        ──► SettingsStore            (%LOCALAPPDATA%\PrivateProxy\settings.json)    │
│      └────────► Elevation                  (перезапуск себя через UAC: --start / --test)  │
└───────────────────────────────────────────────────────────────────────────────────────────┘
```

`winws.exe` перехватывает трафик через WinDivert и применяет правила
`--dpi-desync`. Приложение не вмешивается в пакеты — оно только управляет
жизненным циклом движка и его аргументами.

## Проекты

| Проект | Назначение |
|--------|------------|
| `src/PrivateProxy.Core` | Вся логика без UI: пути, настройки, каталог стратегий, проверка движка, запуск/остановка, тесты, автозапуск, логирование |
| `src/PrivateProxy.App` | WPF-интерфейс, трей, обработка аргументов командной строки, UAC |

### Core

- **`AppPaths`** — единые пути. `data/` и `engine/` ищутся рядом с exe; при запуске
  из `bin/Debug` поиск поднимается вверх по дереву. Пользовательские данные —
  `%LOCALAPPDATA%\PrivateProxy`.
- **`Log`** — потокобезопасный журнал: память (для UI) + файл
  `logs\app-YYYYMMDD.log` (UTF-8). Ошибки записи лога не роняют приложение.
- **`Strategy` / `StrategyCatalog`** — модель стратегии: `id`, `name`, `category`,
  `description`, `recommended`, `args`.
- **`StrategyCatalogLoader`** — читает все `data/strategies/*.json`, валидирует
  обязательные поля и уникальность `id`. Битый файл пропускается с записью в лог.
- **`EngineLocator`** — читает `engine/manifest.json`, считает SHA-256 каждого файла
  и сравнивает с эталоном. Возвращает `EngineStatus` (`Present`, `Verified`, список
  файлов). Приложение отказывается запускать движок, если `Verified == false`.
- **`WinwsRunner`** — владеет процессом `winws.exe`:
  - запуск с `ProcessStartInfo.ArgumentList` (без ручной сборки командной строки);
  - проверка, что процесс не умер через 800 мс после старта;
  - `EventExited` → watchdog: перезапуск с экспоненциальной задержкой 2…30 с;
  - `StopAsync` убивает дерево процессов и ждёт завершения;
  - хранит хвост вывода `winws` и пишет его в общий лог.
- **`StrategyTester`** — последовательно запускает каждую стратегию, ждёт 2.5 с,
  делает HTTP-запросы к `data/targets.json` (по умолчанию YouTube, Discord,
  Google, Googlevideo), затем убивает процесс. Результат: сколько целей ответило,
  средняя задержка, список неудачных целей.
- **`AutostartService`** — `schtasks.exe /Create /SC ONLOGON /RL HIGHEST`.
  Задача запускает `PrivateProxy.exe --autostart`; окно стартует свёрнутым в трей,
  стратегия — сразу.
- **`Elevation`** — определение прав администратора и перезапуск себя через
  `UseShellExecute = true`, `Verb = "runas"`.
- **`ListBootstrap`** — при первом запуске копирует `data/lists/*` в
  `%LOCALAPPDATA%\PrivateProxy\lists` и создаёт пустые `*-user.txt`.
- **`SettingsStore`** — атомарная запись JSON (`.tmp` + `Move`), ошибки не фатальны.

### App

- **`App.xaml.cs`**
  - `Mutex(@"Local\PrivateProxy.SingleInstance")` — второй экземпляр не запускается,
    чтобы два `winws` не конфликтовали за WinDivert.
  - Аргументы: `--start`, `--test`, `--autostart`.
  - Глобальный обработчик необработанных исключений: лог + сообщение, приложение
    продолжает работу.
- **`MainWindow.xaml.cs`**
  - создаёт `NotifyIcon` с меню «Открыть / Запустить-Остановить / Выход»;
  - закрытие окна прячет его в трей (если включено в настройках);
  - при нехватке прав вызывает `Elevation.RelaunchElevated`, сохраняет настройки
    и закрывает текущий экземпляр.
- **`MainViewModel.cs`**
  - состояние UI: выбранная стратегия, статус движка, статус работы, аптайм;
  - команды: запуск, остановка, тест, автозапуск, открытие папок;
  - подписка на `Log.LineWritten` и `WinwsRunner.StateChanged` через
    `SynchronizationContext`.

## Жизненный цикл

### Обычный запуск

1. `AppPaths.EnsureCreated()` → `ListBootstrap.EnsureLists()`.
2. `SettingsStore.Load()`.
3. `StrategyCatalogLoader.LoadAll()` → список стратегий в UI.
4. `EngineLocator.Inspect()` → статус «движок проверен» / ошибка.
5. `AutostartService.IsEnabled()`.
6. Пользователь жмёт «Запустить»:
   - нет прав → UAC-перезапуск с `--start`;
   - есть права → `WinwsRunner.StartAsync` → `winws.exe`.
7. `WinwsRunner` следит за процессом; при падении — перезапуск (если включено).

### Автозапуск

1. Пользователь (под администратором) нажимает «Добавить в автозапуск».
2. Создаётся задача `PrivateProxy` с триггером `ONLOGON` и `RUN LEVEL = HIGHEST`.
3. При входе в систему задача запускает `PrivateProxy.exe --autostart` уже с
   повышенными правами — UAC не показывается.
4. Приложение стартует свёрнутым, выбирает сохранённую стратегию и запускает её.

### Тест стратегий

1. Текущий `winws` останавливается.
2. Для каждой стратегии: запуск → пауза → HTTP-пробы → остановка → пауза 700 мс
   (чтобы драйвер освободил handle).
3. Результаты сортируются; лучшая полностью успешная стратегия выбирается в UI.
   Автоматически она **не** запускается — пользователь нажимает «Запустить».

## Формат стратегии

```json
{
  "id": "general-multisplit",
  "name": "General · multisplit",
  "category": "General",
  "description": "…",
  "recommended": true,
  "args": ["--wf-tcp=80,443", "--filter-tcp=443", "…"]
}
```

Подстановки в `args`:

| Плейсхолдер | Значение |
|-------------|----------|
| `{ENGINE}` | `<папка приложения>\engine\bin` |
| `{LISTS}` | `%LOCALAPPDATA%\PrivateProxy\lists` |
| `{DATA}` | `<папка приложения>\data` |
| `{APP}` | `<папка приложения>` |

Аргументы передаются в `winws.exe` без изменения (кроме подстановок), каждый —
отдельным элементом `ArgumentList`, поэтому пробелы и кавычки в путях безопасны.

## Ограничения текущей версии

- Одновременно активна только одна стратегия.
- Нет автоматического обновления списков и движка (только вручную через скрипты).
- IPSet-фильтрация по умолчанию выключена: `ipset-all.txt` содержит заглушку.
- Движок поставляется готовым бинарником из официального бандла; сборка
  `winws` из исходников — отдельная задача (см. `docs/TRUST.md`).
- Приложение не является службой: обход живёт, пока живёт пользовательская сессия.
